📌 Keterangan Komponen

  • Workflow Manager (FSM)
    Router utama yang mengontrol state & rollback
  • Specialist Agents
    Domain logic (Inventory, Order, Pricing, dll)
  • Coordinator AI
    LLM synthesizer untuk respon ramah user
  • NLU & Event Mapper
    Ingestion pipeline penentu intent

🚀 Alur Eksekusi Workflow

  1. NLU & Intent Extraction
    Pesan user diproses untuk mengambil entitas & intent.
  2. Event & Plan Generation
    EventMapper menentukan strategi & Planner menyusun DAG.
  3. FSM State Routing
    WorkflowManager mengarahkan eksekusi ke service spesialis.
  4. Response Synthesis
    CoordinatorAI menggabungkan data service menjadi teks ramah.
