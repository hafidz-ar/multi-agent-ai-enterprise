Daftar Agen & Tanggung Jawab Alur Kerja

Node / Agen Kategori Layer Tanggung Jawab Utama Keluaran State / DB
NLU Service Pipeline Analyst Eksctraksi maksud (intent), slot-filling entity, dan resolution pengganti kata (coreference). semantic_frame
Event Mapper Pipeline Analyst Mapping intent & entitas menjadi business event standar (misal: CHECK_PRICE, CHECK_STOCK). workflow_event
Planner Service Pipeline Analyst Menyusun urutan langkah eksekusi agen yang diperlukan ke dalam array execution_plan. execution_plan
Workflow Manager Dynamic Router Hub router utama. Membaca elemen pertama dari execution_plan dan mengarahkan alur ke agen yang sesuai. Dynamic Route Dispatch
Inventory Service Specialist Agent Pengecekan jumlah ketersediaan stok produk parfum jadi di gudang. SQLite (inventory)
Production Service Specialist Agent Pengecekan formula/resep parfum dan stok bahan baku esensial. Memicu PO jika bahan kurang. SQLite (ingredients)
Procurement Service Specialist Agent Pembuatan Purchase Order (PO) otomatis untuk pembelian bahan baku ke supplier. SQLite (purchase_orders)
Pricing Service Specialist Agent Perhitungan harga produk berdasarkan varian ukuran (30ml, 50ml, 100ml) & diskon promo. SQLite (perfume_catalog)
Reporting Service Specialist Agent Penyajian histori transaksi penjualan, top seller, & estimasi pendapatan bisnis. SQLite (sales_history)
Order Service Specialist Agent Pencatatan transaksi pembelian baru & pemotongan stok secara terintegrasi. SQLite (sales_history)
Coordinator AI Response Synthesizer Menyintesis seluruh data hasil eksekusi agen menjadi jawaban bahasa alami yang ramah pengguna. Groq LLM (llama-3.1)

Alur Eksekusi Nyata Berdasarkan Kasus (Execution Scenarios)

1. Query Cek Harga ("Berapa harga Ratione Noir?")

Single service execution plan disiapkan oleh Planner Service.

NLU ➔ EventMapper ➔ Planner ➔ WorkflowManager ➔ PricingService ➔ WorkflowManager ➔ CoordinatorAI
2. Cek Stok & Restock Produksi ("Pesan 50 botol")

Multi-step plan bercabang otomatis dari Inventory ke Production & Procurement.

NLU ➔ Planner ➔ WorkflowManager ➔ Inventory ➔ Production ➔ Procurement ➔ CoordinatorAI
3. Checkout Pembelian ("Beli YSL 100ml 2 botol")

Pencatatan transaksi di DB sales & update stok produk.

NLU ➔ Planner ➔ WorkflowManager ➔ OrderService ➔ InventoryService ➔ CoordinatorAI
